# Homepage Non-AI Metadata Implementation Plan

> **For agentic workers:** Follow this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove AI positioning from homepage marketing metadata and visible homepage review content.

**Architecture:** Keep homepage metadata in `src/pages/index.html` front matter and repeated homepage review content in `src/_data/home.js`. Supersede the earlier Play Store alignment plan because the website's public marketing language does not use AI as the homepage positioning.

**Tech Stack:** Eleventy, Nunjucks front matter, static HTML metadata.

---
