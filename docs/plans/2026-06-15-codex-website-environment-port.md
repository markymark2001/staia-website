### Task 2: Add Website Setup/Cleanup Scripts

**Files:**
- Create: `.codex/scripts/setup-worktree.sh`
- Create: `.codex/scripts/cleanup-worktree.sh`

- [ ] **Step 1: Add setup script**

Create `.codex/scripts/setup-worktree.sh` with:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT_DIR="${CODEX_WORKTREE_PATH:-}"
if [[ -z "$ROOT_DIR" ]]; then
  ROOT_DIR="$(git rev-parse --show-toplevel)"
fi

fail() {
  printf '[staia-website-setup] ERROR: %s\n' "$*" >&2
  exit 1
}

command -v npm >/dev/null 2>&1 || fail "npm is required."
[[ -f "$ROOT_DIR/package.json" ]] || fail "package.json not found at $ROOT_DIR."
[[ -f "$ROOT_DIR/package-lock.json" ]] || fail "package-lock.json not found at $ROOT_DIR."

printf '[staia-website-setup] Installing locked npm dependencies...\n'
npm --prefix "$ROOT_DIR" ci

printf '[staia-website-setup] Building Eleventy site...\n'
npm --prefix "$ROOT_DIR" run build

printf '[staia-website-setup] Ready. Built artifact: %s/dist\n' "$ROOT_DIR"
```

Expected: fresh Codex worktrees get dependencies and a generated `dist/` artifact before an action runs.

- [ ] **Step 2: Add cleanup script**

Create `.codex/scripts/cleanup-worktree.sh` with:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT_DIR="${CODEX_WORKTREE_PATH:-}"
if [[ -z "$ROOT_DIR" ]]; then
  ROOT_DIR="$(git rev-parse --show-toplevel)"
fi

printf '[staia-website-cleanup] Removing generated Eleventy artifact at %s/dist\n' "$ROOT_DIR"
rm -rf "$ROOT_DIR/dist"
```

Expected: Codex can clean generated website output during worktree cleanup without touching authored source.

- [ ] **Step 3: Make scripts executable**

Run:

```bash
chmod +x .codex/scripts/setup-worktree.sh .codex/scripts/cleanup-worktree.sh
```

Expected: both scripts are executable.
